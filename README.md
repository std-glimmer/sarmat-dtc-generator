# SarmatDTC — генератор DTC для серверов SARMAT (DCS World)

На сервере, в названии которого есть **SARMAT**, мод берёт обстановку с
[живой карты](https://baikalprimestudio.com/map.html) и при выборе слота сам создаёт картриджи DTC
для вашей коалиции: линию фронта, вражеские ЗРК, группы войск и FARP-ы. Работает на Сирии и Кавказе.

- [Для игроков](#для-игроков): установка, использование, настройки, проблемы
- [Для разработчиков](#для-разработчиков): устройство, новые модули, тесты

# Для игроков

## Что попадает в картридж

| Модуль | Файл | Что размечается |
|---|---|---|
| AH-64D | `SARMAT_AH-64D_BLK_II.dtc` | **Control Measures** (C51–C99): вражеские и свои группы у фронта, FARP-ы. **Targets** (T01–T25): вражеские ПВО с типом. **Lines**: линия фронта (FLOT) |
| F-16C | `SARMAT_F-16C_50.dtc` | **GEO LINES**: линия фронта (до 25 точек). **THREAT PTS**: вражеские ЗРК с кольцами (до 15) |
| F/A-18C | `SARMAT_FA-18C_hornet.dtc` | **SA → FLOT**: линия фронта (3 линии × 7 точек). **SA → MEZ THRTS**: вражеские ЗРК с кольцами (до 40) |
| F-14B(U) | `SARMAT_F-14BU.dtc` | Линия фронта в навигационном плане 1 |
| F-15E | — | Пример для разработчиков: данные собираются, файл пока не пишется |

Файлы лежат в `Saved Games\DCS.openbeta\DTC\` (у новых установок — `Saved Games\DCS\DTC\`;
другую папку можно задать в [настройках](#папка-для-картриджей)) и перезаписываются при каждом выборе слота. Всё остальное в картридже (радио, CMDS, лазерные коды,
маршруты) остаётся по умолчанию DCS или берётся из вашего [базового картриджа](#базовый-картридж).

### AH-64D: картинка TSD на один вылет

Apache получает не всю карту, а то, что важно для вылета с вашей базы:

- только район действий: от базы до фронта и ещё 80 км за ним;
- один символ на позицию: группы ближе 2 км друг к другу сливаются в одну точку;
- свои войска — только в 10 км от фронта (чтобы не стрелять по своим), свои ПВО не показываются;
- приоритет — у объектов ближе к фронту и к вашей базе, вражеские важнее своих.

На TSD вместо номера точки виден короткий текст: **число машин** у групп, `F01…` у своих FARP,
`E01…` у вражеских. Подробности (тип, состав) — в заметке точки на странице POINT.
Заполняются только T01–T25: точки, которые экипаж сохраняет в кабине, попадают в свободные T26–T50.

### F-16C и F/A-18C: кольца ЗРК

Берутся вражеские ЗРК с радиусом от 6 км (ЗУ, ПЗРК, SA-9/13 и Avenger отсекаются), одно кольцо
одного типа в радиусе 5 км. Сначала идут кольца, которые ближе всего к фронту или перекрывают его.

## Требования

- Windows 10/11 (используется встроенный `curl.exe`);
- DCS World (Сирия или Кавказ), сервер с **SARMAT** в названии.

## Установка

1. Найдите папку DCS в `Saved Games`: та, где есть `Logs\dcs.log`. Обычно это
   `%USERPROFILE%\Saved Games\DCS\` (DCS 2.9+) или `%USERPROFILE%\Saved Games\DCS.openbeta\`.
2. Скопируйте в неё папку `Scripts` из репозитория (с объединением папок).
3. Запустите DCS. В `Logs\dcs.log` должна появиться строка `SARMAT.DTC ... loaded, version ...`.

**Обновление** — скопируйте `Scripts` заново. Ваш `config.user.lua` сохранится: его нет в поставке.
**Удаление** — удалите `Scripts\Hooks\SarmatDTC-hook.lua` и папку `Scripts\SarmatDTC`.

## Как пользоваться

1. Подключитесь к серверу SARMAT. Мод сразу начнёт фоново скачивать карту (обычно несколько секунд, игра не тормозит).
2. Выберите слот. Картриджи для вашей стороны пишутся сразу из последних данных, а после свежей
   загрузки — ещё раз.
3. В чате появится локальное сообщение (его видите только вы), например
   `SarmatDTC: BLUE DTC ready (Hatay): AH-64D, F-16C, FA-18C` — сторона, база спавна, модули.
4. Загрузите `SARMAT_<модуль>` в менеджере DTC перед вылетом.

Если обстановка на карте не поменялась с прошлой записи, файлы не перезаписываются и в чат ничего не пишется.

### Сообщения в чате

| Пометка | Что значит |
|---|---|
| `- download failed` / `- download timed out` | Сайт не ответил, картриджи построены из прошлой загрузки |
| `- map data 25 min old` | Данным больше 10 минут: обстановка могла измениться |
| `- 1 error(s), see dcs.log` | Один из модулей не собрался, остальные записаны |
| `..., no DTC written` | Ничего не записано (например, данные старше 3 часов или с другой карты). Файл `SARMAT_*.dtc` на диске при этом **устарел** |

## Настройки — `Scripts\SarmatDTC\config.user.lua`

`config.lua` — настройки по умолчанию, при обновлении он заменяется. Свои настройки пишите
в `config.user.lua` рядом с ним (создайте файл сами). Указывайте только то, что меняете:
`AIRCRAFT` и `DTC_DIR` заменяют значение из `config.lua`, `BASE_DTC` и `OPTIONS` — по отдельным самолётам.

```lua
-- Scripts/SarmatDTC/config.user.lua
return {
    AIRCRAFT = {             -- для каких самолётов генерировать
        "AH-64D_BLK_II",
        "F-16C_50",
    },
    DTC_DIR = "DTC\\SARMAT", -- папка для картриджей (по умолчанию "DTC")
    BASE_DTC = {             -- ваш картридж: из него берётся всё, что мод не заполняет
        ["AH-64D_BLK_II"] = "AH-64D_BLK_II_DTC_SAR_3.dtc",
    },
    OPTIONS = {              -- опции модулей (таблицы ниже)
        ["AH-64D_BLK_II"] = { CTRLM_FARPS = 15, TGT = 50 },
        ["FA-18C_hornet"] = { THREATS = 0 },
        ["F-14BU"]        = { enabled = false },
    },
}
```

Файлы перечитываются при каждом старте миссии, перезапускать DCS не нужно. Ошибка в
`config.user.lua` — предупреждение в `dcs.log`, тогда используется только `config.lua`.
Значение опции вне допустимых границ прижимается к ним (с предупреждением в логе).

### Папка для картриджей

`DTC_DIR` — куда писать `SARMAT_<тип>.dtc`. Путь относительно `Saved Games\DCS.openbeta`
(`"DTC\\SARMAT"`), полный (`"D:\\DCS DTC"`, `"\\\\server\\share"`) или с `%ENV%`. В строках Lua
обратную косую черту нужно удваивать. Папка создаётся сама. Импорт в менеджере DTC открывает
`Saved Games\...\DTC\`: перейдите в нужную папку в этом окне. Для одного самолёта папку можно
задать отдельно: `OPTIONS[тип].outputs["dcs-dtc"].dir` (см. [Опции](#опции)). Базовые картриджи
(`BASE_DTC`) по-прежнему ищутся в `Saved Games\...\DTC\`: туда их сохраняет редактор DTC.

### Базовый картридж

`BASE_DTC[тип]` — обычный DCS-картридж, сохранённый в редакторе DTC: имя файла из папки `DTC`
или полный путь. Мод берёт его копию и заменяет только свою разметку (фронт, угрозы, точки).
Навигация базового файла, сделанного на другой карте, не используется, остальные настройки — да.
Указывать сам `SARMAT_<тип>.dtc` нельзя.

### Опции

Общие для всех модулей: `enabled = false` — не генерировать; `outputs = { ["dcs-dtc"] = { dir = "...", file = "..." } }` —
другая папка или имя файла (подстановки `{type}`, `{side}`, `{terrain}`; путь относительно
`Saved Games\DCS.openbeta`, абсолютный или с `%ENV%`).

**AH-64D** (`AH-64D_BLK_II`)

| Опция | По умолч. | Границы | Смысл |
|---|---|---|---|
| `CTRLM` | 49 | 0–49 | Число Control Measures |
| `CTRLM_FARPS` | nil | 0–49 | nil — FARP-ы в общем списке; N — до N мест зарезервировать под FARP-ы |
| `TGT` | 25 | 0–50 | Число Targets/Threats. Больше 25 — экипажу негде сохранять свои точки |
| `LINES` / `LINE_PTS` | 15 / 4 | 0–15 / 2–4 | Линии фронта и вершин в линии |
| `AO_DEPTH_M` | 80000 | ≥ 0 | Глубина района за фронтом, м (0 — вся карта) |
| `CLUSTER_M` | 2000 | ≥ 0 | Радиус слияния групп, м (0 — без слияния) |
| `OWN_FRONT_M` | 10000 | ≥ 0 | Свои войска не дальше этого от фронта, м (0 — все) |
| `OWN_AD` | false | — | Показывать свои ПВО |
| `SPAWN_WEIGHT` | 0.5 | ≥ 0 | Вес расстояния до базы спавна (0 — не учитывать) |
| `ENEMY_FACTOR` | 0.7 | ≥ 0 | Множитель веса вражеских (1 — без предпочтения) |
| `RING_CAP_M` | 15000 | ≥ 0 | Максимум кольца угрозы при сортировке Targets, м |

Вся карта без отбора: `{ TGT = 50, AO_DEPTH_M = 0, CLUSTER_M = 0, OWN_FRONT_M = 0, OWN_AD = true }`.

**F-16C** (`F-16C_50`)

| Опция | По умолч. | Границы | Смысл |
|---|---|---|---|
| `POINTS` | 25 | 2–25 | Точек линии фронта |
| `THREATS` | 15 | 0–15 | Колец ЗРК (0 — оставить угрозы из миссии) |
| `MIN_RANGE` | 6000 | ≥ 0 | Минимальный радиус ЗРК, м |
| `DEDUP_M` | 5000 | ≥ 0 | Одно кольцо одного типа в этом радиусе, м |

**F/A-18C** (`FA-18C_hornet`)

| Опция | По умолч. | Границы | Смысл |
|---|---|---|---|
| `LINES` / `LINE_PTS` | 3 / 7 | 1–3 / 2–7 | Линии фронта и точек в линии |
| `THREATS` | 40 | 0–40 | Колец ЗРК (0 — оставить угрозы из миссии) |
| `MIN_RANGE` / `DEDUP_M` | 6000 / 5000 | ≥ 0 | Как у F-16C |
| `THREAT_LEVEL` | 1 | 1–3 | Уровень угрозы колец |

**F-14B(U)** (`F-14BU`): `LINES` 2 (1–4), `LINE_PTS` 9 (2–9); всего не больше 20 точек на план.

## Если не работает

Откройте `Saved Games\DCS.openbeta\Logs\dcs.log` и найдите строки `SARMAT.DTC`.

| Симптом | Причина / что делать |
|---|---|
| Нет строки `loaded, version` | Мод не установлен в ту папку `Saved Games` (см. [Установка](#установка)) |
| Нет сообщения в чате | В названии сервера нет «SARMAT», выбран слот зрителя или модуль не в `AIRCRAFT` |
| `download failed (...: curl exit 28, timeout)` | Сайт карты не ответил; повторите выбор слота через минуту |
| `base DTC is for another map, not used` | Базовый картридж сделан на другой карте, его навигация пропущена |
| `config.lua option: ... out of range` | Опция вне границ, использовано ближайшее допустимое значение |

Ручная проверка загрузки (из папки `Saved Games\DCS.openbeta`):

```powershell
wscript //B //Nologo Scripts\SarmatDTC\fetch.vbs https://baikalprimestudio.com/data/
```

Результат — `Scripts\SarmatDTC\cache\done-manual.flag` (`ok` или `fail <файл> <код curl>`).

> **Безопасность.** `config.lua`, `config.user.lua` и файлы в `aircraft/` — код на Lua, который DCS
> выполняет с полным доступом к системе. Не кладите модули от незнакомых людей и не вставляйте чужой
> `config.user.lua`, не прочитав его. Данные сайта кодом не являются: они только разбираются как JSON,
> битые записи пропускаются, ответ больше 5 МБ не принимается.

# Для разработчиков

Полный справочник по устройству, принятым решениям и ловушкам окружения — [AGENTS.md](AGENTS.md).
API модуля — в [`aircraft/_template.lua`](Scripts/SarmatDTC/aircraft/_template.lua).

## Файлы

| Путь | Назначение |
|---|---|
| `Scripts/Hooks/SarmatDTC-hook.lua` | Загрузчик (DCS исполняет `Scripts/Hooks/*` в GUI-окружении) |
| `Scripts/SarmatDTC/SarmatDTC.lua` | Связь с DCS: колбэки, сервер и сторона, загрузка, кэш, кодировщики, запись файлов. `CONFIG` и `VERSION` в начале |
| `Scripts/SarmatDTC/SarmatDTC_core.lua` | Библиотека без DCS: данные карты → `situation`, классификация юнитов и ПВО, геометрия, загрузка и запуск модулей, базовый картридж |
| `Scripts/SarmatDTC/aircraft/<type>.lua` | Один файл на модуль DCS, подхватывается автоматически (`_*.lua` пропускаются) |
| `Scripts/SarmatDTC/config.lua` | Настройки по умолчанию; поверх — `config.user.lua` игрока |
| `Scripts/SarmatDTC/fetch.vbs`, `fetch.cmd` | Фоновая загрузка `status.json`/`units.json` через `curl.exe` (CRLF!) |
| `Scripts/SarmatDTC/tests/` | Офлайн-тесты, фикстуры (снимок карты, Сирия) и эталоны |

`.gitignore` — allowlist: репозиторий лежит в самой папке `Saved Games\DCS.openbeta`, новый файл
нужно разрешить строкой `!путь`.

## Поток данных

```
onMissionLoadEnd ── сервер SARMAT? ──► fetch.vbs → fetch.cmd → curl ──► cache/*-<id>.part + done-<id>.flag
onSimulationFrame ── флаг ok ──► status.json + units.json (ставятся на место парой)
onPlayerChangeSlot ── сторона, база спавна ──► generate:
    loadCache → inputKey (без изменений — выход) → decodeCache → core.situation()
      → aircraft/<type>.lua: build → "dcs-dtc" (+ BASE_DTC), outputs → другие форматы
      → ENCODERS (dcs-dtc / json / lua / text) → writeFileAtomic → чат и dcs.log
```

- `situation` нейтральна: ключи классов (`"SA-11"`, `"armor"`), координаты DCS x/z, без символов
  конкретных самолётов. Символы и лимиты — только в файле модуля.
- Каждый модуль, выход и колбэк выполняется в `pcall`: сбой одного не ломает остальные и GUI игры.
- Данные сайта не доверенные: записи без числовых координат пропускаются и считаются.

## Новый модуль

1. Найти `CoreMods/aircraft/<module>/DTC/` в установке DCS: `<type>_DTC.lua` (`type`, `setData`,
   `mirror_*`, проверка `terrain`) и лимиты `MAX_*` секций. Образцы — файлы, сохранённые редактором DTC.
2. Скопировать `aircraft/_template.lua` в `aircraft/<type>.lua`, заполнить `type`, `options`,
   `limits` (для каждой числовой опции) и `build(s, lib, opt)`.
3. Добавить тип в `AIRCRAFT` в `config.lua`. Ядро и `SarmatDTC.lua` трогать не нужно.
4. Добавить специфичные проверки в `tests/test_core.lua`, обновить эталоны (`-UpdateExpected`), прогнать тесты.

Выход для другой DTC-системы — элемент `outputs = { { id, format, dir, file, build } }` в модуле,
по умолчанию `enabled = false`. Новый формат файла — функция в `ENCODERS` в `SarmatDTC.lua`.
Альтернативный алгоритм заполнения — `variants` модуля, выбор через `OPTIONS[type].variant`.

## Тесты

```powershell
powershell -ExecutionPolicy Bypass -File "Scripts\SarmatDTC\tests\run_tests.ps1"
```

Параметры: `-DcsDir <папка DCS>` (иначе `DCS_DIR` или реестр), `-OutDir <папка>` — сохранить
сгенерированные DTC, `-UpdateExpected` — перезаписать эталоны (затем проверить дифф в git).

- `test_core.lua` — ядро и все модули: лимиты, сцепка линий, варианты, `limits` опций, битые данные,
  побайтное сравнение с эталонами `tests/fixtures/expected/`.
- `test_hook.lua` — `SarmatDTC.lua` с заглушками API DCS и реальной цепочкой `wscript → cmd → curl`
  по `file://`, из папки с кириллицей в пути.

Интерпретатор — `bin\luae.exe` из установки DCS (Lua 5.1). Тесты не запускают саму игру: изменения
в колбэках проверяйте на сервере по `dcs.log`. Сайт карты при отладке не нагружайте — есть фикстуры.

## Выпуск

Поднять `VERSION` в `SarmatDTC.lua` (видна в `dcs.log` игрока), прогнать тесты, проверить `file fetch.cmd`
(должен быть CRLF).
