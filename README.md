# SarmatDTC — генератор DTC для серверов SARMAT (DCS World)

При подключении к серверу, в названии которого есть **SARMAT**, мод берёт обстановку с
[живой карты](https://baikalprimestudio.com/map.html) и при выборе слота создаёт картриджи DTC
для вашей коалиции:

| Модуль | Что размечается |
|---|---|
| AH-64D | Control Measures: свои и вражеские группы, свои ПВО, FARP-ы. Targets/Threats: вражеские ПВО с типом. Линия фронта (FLOT). В первую очередь — объекты у фронта и рядом с вашей базой спавна, вражеские в приоритете |
| F-16C | Линия фронта (GEO LINES), вражеские ЗРК с кольцами (THREAT PTS, до 15) |
| F/A-18C | Линия фронта (SA → FLOT), вражеские ЗРК с кольцами (SA → MEZ THRTS, до 40) |
| F-14BU | Линия фронта (план навигации 1) |
| F-15E (пример) | Пока только подготовка данных: спавн, фронт, угрозы, цели, свои, FARP-ы. Файл не пишется, целевой формат ещё не выбран |

Файлы `Saved Games\DCS.openbeta\DTC\SARMAT_<модуль>.dtc` перезаписываются при каждом выборе слота.
Загрузите их в окне DTC перед вылетом. Остальные настройки картриджа (радио, CMDS и т.д.) берутся
из базового файла, если он задан в `config.lua`, иначе остаются по умолчанию.

После записи в чат приходит короткое сообщение, например
`SarmatDTC: BLUE DTC ready (Hatay): AH-64D, F-16C, FA-18C`. Если загрузить свежие данные не удалось,
картриджи строятся из прошлой загрузки, а в сообщении указывается её возраст
(`- download failed, map data 2 h old`). Данные старше 3 часов не используются, и в чате появляется
`... no DTC written`: файл `SARMAT_*.dtc` на диске в этом случае устарел.

## Установка

Скопируйте папку `Scripts` из репозитория в `%USERPROFILE%\Saved Games\DCS.openbeta\`.
Нужны Windows 10/11: используется встроенный `curl.exe`.

## Настройки — `Scripts/SarmatDTC/config.lua`

```lua
AIRCRAFT = {             -- для каких самолётов генерировать; ненужное закомментируйте
    "AH-64D_BLK_II",
    "F-16C_50",
    -- "F-14BU",
},
BASE_DTC = {             -- ваш DCS-картридж, из которого берётся всё, что скрипт не заполняет
    ["AH-64D_BLK_II"] = "AH-64D_BLK_II_DTC_SAR_3.dtc",   -- (радио, лазерные коды, CMDS, маршруты…)
},
OPTIONS = {              -- опции отдельных модулей и их выходов
    ["AH-64D_BLK_II"] = { CTRLM_FARPS = 15 },
},
```

Навигационные данные базового файла, сделанного на другой карте, не используются: остальные
его настройки при этом берутся.

Файл перечитывается при каждом старте миссии, перезапускать DCS не нужно.

> **Безопасность.** `config.lua` и файлы в `aircraft/` — это код на Lua, который DCS выполняет
> с полным доступом к системе (запуск программ, запись файлов). Не кладите в `aircraft/` модули
> от незнакомых людей и не вставляйте чужой `config.lua` целиком, не прочитав его. Данные с сайта
> карты кодом не являются: они только разбираются как JSON.

## Новые модули и другие DTC-системы

Логика каждого модуля — отдельный файл в `Scripts/SarmatDTC/aircraft/`. Чтобы добавить модуль,
скопируйте `aircraft/_template.lua` в `aircraft/<тип DTC>.lua`, заполните его и добавьте тип в `config.lua`.

Помимо нативного DTC DCS, модуль может выдавать файлы для других DTC-систем (`outputs`): форматы
`json`, `lua`, `text`, своя папка (в том числе вне `Saved Games`) и имя файла с подстановками
`{type}`, `{side}`, `{terrain}`. Включить, отключить или перенаправить выход можно в
`config.lua`: `OPTIONS[тип].outputs[id] = { enabled = true, dir = "..." }`.
